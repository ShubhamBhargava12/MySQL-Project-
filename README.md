# 🏏 Cricket Data Analysis (MySQL Project)

This repository contains a comprehensive data analysis project focused on cricket statistics using **MySQL Workbench**. The project involves importing raw cricket data, structuring it within a relational database, and writing complex SQL queries to extract meaningful insights about player performances, match outcomes, and team statistics.

---

## 📂 Repository Structure

*   **`Cricket_data1.csv`**: The raw dataset containing detailed cricket match and player statistics.
*   **`cricket data project for work bench.sql`**: The main SQL script containing database creation, table structures, and analytical queries.
*   **`questions file1.pdf`**: A document listing the business questions and problems that this project solves.

---

## 🛠️ Tech Stack & Tools

*   **Database Management System:** MySQL
*   **Interface:** MySQL Workbench
*   **Data Source:** CSV Dataset

---

## 📊 Key Insights & Features Covered

The SQL queries in this project address various critical analytical questions, including:
*   **Player Performance Tracking:** Identifying top-performing batsmen and bowlers based on runs, strike rates, and wickets.
*   **Match Analysis:** Evaluating team performance across different venues and match conditions.
*   **Statistical Breakdown:** Calculating averages, economic rates, and consistency metrics using SQL aggregation and window functions.

## 🚀 How to Run This Project

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/ShubhamBhargava12/MySQL-Project-.git](https://github.com/ShubhamBhargava12/MySQL-Project-.git)
    ```
2.  **Set Up the Database:**
    *   Open **MySQL Workbench**.
    *   Create a new schema/database.
    *   Import the `Cricket_data1.csv` file using the *Table Data Import Wizard*.
3.  **Execute Queries:**
    *   Open and run the `cricket data project for work bench.sql` script to see the analytical queries and results.
